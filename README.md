# Portofolio Cinta Amandha Putri

Website portofolio statis (HTML + CSS + JS, tanpa build) untuk Cinta Amandha Putri, lulusan D4 Teknologi Laboratorium Medis.

## Struktur

```
index.html
assets/
  CV_Cinta_Amandha_Putri.pdf
  img/          foto profil dan galeri kegiatan
  sertifikat/   gambar sertifikat
```

## Menambah foto galeri

Simpan foto di `assets/img/` dengan nama berikut. Foto yang belum ada otomatis tidak ditampilkan.

| Nama file | Isi foto |
| --- | --- |
| `pkl-1.jpg`, `pkl-2.jpg` | PKL di RSUD Dr. Iskak Tulungagung |
| `lab-1.jpg` | Sedang bekerja di laboratorium |
| `skripsi-1.jpg` | Pengambilan data penelitian |
| `hima-1.jpg` | Kegiatan HIMA D4 TLM |
| `wisuda.jpg` | Foto wisuda |

## Publikasi dengan GitHub Pages

1. Buat repository baru, upload seluruh isi folder ini (bukan foldernya).
2. Buka Settings > Pages, pilih branch `main` dan folder `/ (root)`, lalu Save.
3. Situs akan tersedia di `https://<username>.github.io/<nama-repo>/`.
